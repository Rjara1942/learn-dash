# Fase 0 — Python mínimo viable

## Objetivo

Tener suficiente Python para no tropezar con sintaxis mientras aprendes Dash.
**No** necesitas dominar Python entero. Solo lo que usarás.

## Qué aprender

- [ ] Estructuras: listas, diccionarios, tuplas
- [ ] Funciones y argumentos por defecto
- [ ] Imports y estructura de módulos
- [ ] pandas: `DataFrame`, filtros, `groupby`, `merge`, `pivot`
- [ ] Entornos virtuales: `venv` o `conda`
- [ ] Manejo básico de archivos (leer CSV/Excel)

## Qué NO necesitas por ahora

- Programación orientada a objetos avanzada (clases con herencia)
- Async / await
- Decoradores personalizados (los usarás pero no los escribirás)
- Type hints avanzados

## Ejercicios sugeridos

1. Reproducir en pandas 3 análisis que ya hayas hecho en R con dplyr
2. Leer un CSV, filtrar, agrupar, y exportar a Excel
3. Escribir una función que tome un DataFrame y devuelva estadísticas resumidas
